# Pythia 2.8B release result

This directory freezes the completed Pythia 2.8B scale replication for the controlled WikiText systems study. Values are copied directly from the successful GitHub Actions evidence artifact generated by workflow run `31466226471` at experiment commit `139688d1c5262ed680b7c42b6e2f4222a34a136d`.

## Result

The experiment completed successfully on a single NVIDIA A100-SXM4-80GB under the pinned deterministic environment.

Identity replay reproduced the original run exactly across 388 model tensors and 2,775,208,960 model elements:

- exact: `true`
- unequal tensors: `0`
- unequal elements: `0`
- maximum absolute difference: `0.0`
- L2 difference: `0.0`
- optimizer hash equal: `true`
- shared model SHA-256: `c68bcd5092e7c28dbb94e812f6ad62b64d4321bb4af0af3ef7784bb494048759`
- shared optimizer SHA-256: `fbaa0735422bc75e4855d5bb4e56b94d4cdc40a7a4c5a63b488f9a142379915f`

For the random 5% deletion scenario, 1,013 of 20,256 records were selected for deletion. The materialized replay store contains 19,243 retained records and reports `forgotten_ids_present: false`.

Trace-preserving replay from that physically redacted store reproduced the deletion oracle exactly:

- exact: `true`
- unequal tensors: `0`
- unequal elements: `0`
- maximum absolute difference: `0.0`
- L2 difference: `0.0`
- optimizer hash equal to oracle: `true`
- shared oracle/replay model SHA-256: `e23165a25eed20be896bd40ea3913dcf6e644c5f10ff54c16a35571a115df6f4`
- shared oracle/replay optimizer SHA-256: `e7c6cce3619f0557275c8ae8e6a5db3b1e001ab868d844003c1ba17a1144ba89`

The earliest affected optimizer step was 2, so the deletion oracle and replay both start from the step-zero checkpoint.

## Claim boundary

This result supports a controlled, single-GPU systems claim: under this pinned environment, Pythia 2.8B identity replay is exact, and trace-preserving replay after physical deletion of a random 5% subset reproduces the trace-preserving deletion oracle exactly, including optimizer state.

It does not establish multi-GPU exactness, legal compliance, semantic forgetting quality on standardized benchmarks, superiority over approximate unlearning methods, or exactness under arbitrary hardware/software environments.
