For all four deletion geometries, slot-preserving replay matched the trace-preserving deletion oracle exactly, including the optimizer hash. Physically filtering forgotten rows and densely repacking retained rows both diverged from that oracle.

The replay data stores were materialized without the forgotten records before replay. The `forgotten_ids_present` field is `false` in every scenario.
